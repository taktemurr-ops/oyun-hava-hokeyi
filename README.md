# Hava Hokeyi (oyun-hava-hokeyi)

Masa Oyunları merkez uygulamasındaki hava hokeyi oyunu. Parmağınla tokmağı sürükler, diski rakibin kalesine sokar, kendi kaleni korursun.

- 33 dil; kampanya, günlük, zen, sonsuz ve zamana karşı modları
- Rakip zorluğu seviyeyle artar; her seviye botla oynanıp doğrulanır
- Güçlendirici: Kale kalkanı (10 saniye kalene gol girmez)
- Testler: `flutter test`
